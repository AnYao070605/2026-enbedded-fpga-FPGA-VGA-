# Skill Package 技能包

> 本目录存放可被他人直接复用的经验。每项写明：适用场景、使用方法、失效条件、已验证效果。
> 以下条目来自本工程已实现的设计方法；涉及大模型协作的部分请按实际情况补充。

## Skill 1: 无帧缓存的 VGA 实时像素绘制

- 类型：design method（对应 `src/kiln_video.v`、`src/top_kiln.v`）
- 适用场景：资源受限、不需要回读整帧的 VGA 显示
- 使用方法：维护 `(x, y)` 扫描坐标，在可见区按坐标组合逻辑直接输出 RGB，同步信号按行/场计数区间生成
- 失效条件：需要随机访问历史像素或复杂帧缓冲的场景不适用
- 已验证效果：640×480@60Hz RGB565 稳定输出，片内无需外部显存

## Skill 2: 按键跨时钟域同步与消抖

- 类型：design method（对应 `src/top_kiln.v` 同步与帧采样逻辑）
- 适用场景：异步机械按键进入同步时钟域
- 使用方法：两级寄存器同步 + 帧节拍采样，单次按下只产生一个脉冲，长按单独标记
- 失效条件：需要模拟量或更高分辨率手势识别的场景
- 已验证效果：`tb_kiln_board.sv` 验证抖动不会误触发

## Skill 3: 暂停不丢秒的计时分频

- 类型：design method（对应 `src/top_kiln.v` 的 `second_phase`）
- 适用场景：可暂停/恢复的秒级计时器
- 使用方法：仅在运行态累加相位计数器，暂停时冻结，恢复后从原值继续，保证只统计有效时间
- 失效条件：需要统计暂停时长或日历功能时需扩展
- 已验证效果：`tb_kiln_core.sv` 验证暂停边界与秒脉冲不提前、不丢失

## Skill 4: 带质量门禁的可复现构建

- 类型：verification script（对应 `build/build.tcl`）
- 适用场景：命令行一键重建 Vivado 工程
- 使用方法：tcl 完成综合、实现、bit/mcs 生成，并对 DRC 错误/严重警告和正负时序裕量做失败检查
- 失效条件：更换器件或 IP 时需修改脚本中的 part 与文件列表
- 已验证效果：DRC 零违规，WNS +12.448 ns、WHS +0.130 ns
